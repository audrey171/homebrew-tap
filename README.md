# Cargo Paste Homebrew tap

Release preparation is in progress. Installation is not live yet.

Once the signed release is published, the installation command will be:

```sh
brew install --cask audrey171/tap/cargo-paste
```

Cargo Paste supports Apple Silicon and Intel Macs running macOS Sonoma 14 or later.
Open Cargo Paste after installation. Enable Accessibility for hold-Command-V.

This repository contains Homebrew packaging only; downloads are hosted in
`audrey171/cargo-paste-releases`.
