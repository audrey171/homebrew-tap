# Cargo Paste Homebrew tap

Install Cargo Paste for Mac:

```sh
brew install --cask audrey171/tap/cargo-paste
```

Cargo Paste supports Apple Silicon and Intel Macs running macOS Sonoma 14 or later.
Open Cargo Paste after installation. To use hold-Command-V across apps, enable Cargo Paste in System Settings → Privacy & Security → Accessibility.

Click the menu-bar icon to open or close the drawer. Right-click it for Show / Hide and Quit.

App downloads: https://github.com/audrey171/cargo-paste-releases/releases
Website: https://cargopaste.com/

This repository contains Homebrew packaging only.
